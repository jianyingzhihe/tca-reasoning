# 01 研究目标与当前发现

日期：2026-05-19

本文回答三个问题：

1. 我们一开始想证明什么；
2. 现在实验实际发现了什么；
3. 这些发现到底能说明什么，不能说明什么。

这份文档是项目主线的“口径收束版”。如果后面写论文、报告、答辩，优先以这里的表述为准。

---

## 0. 专有名词解释

**VLM**

Vision-Language Model，视觉-语言模型。这里指能同时输入图片和文本问题，并输出文本答案的多模态模型。

**OK-VQA**

Open Knowledge Visual Question Answering，一个视觉问答数据集。问题通常需要结合图像和常识知识回答。

**Prompt**

给模型的提示语。我们主要比较过几类 prompt：

- `B_direct`：直接回答，要求输出短答案；
- `D_visual_only`：要求使用 visual evidence，再输出短答案；
- `C_step_only`：要求 step-by-step，但不显式强调 visual evidence；
- `A_step_visual`：同时包含 step-by-step 和 visual evidence。

**Prompt A/B**

早期实验中，Prompt A 通常指“step-by-step + visual evidence”的复杂提示，Prompt B 指直接回答。后来发现 A/B 不干净，因为 A 同时混入了两个因素：逐步推理和视觉证据提示。

**Target token**

模型输出答案时，某个关键答案词对应的 token。例如答案是 `Spanish`，我们会关注生成 `Spanish` 这个 token 时的 logit / rank。

**Logit**

模型在输出下一个 token 前，对每个候选 token 给出的未归一化分数。logit 越高，模型越倾向输出该 token。

**Target rank**

目标答案 token 在所有候选 token 中的排名。rank 越小越好，rank=1 表示目标 token 是模型最想输出的 token。

**Margin**

目标答案 token 和最强竞争 token 的 logit 差：

```text
margin = logit(target) - logit(top competitor)
```

margin 越大，说明目标答案越稳。

**Node / feature node**

机制解释中的内部特征节点。可以粗略理解为模型内部某个层、某个位置、某个特征维度上的可干预单元。

**Route**

模型内部从输入到答案输出附近的一条功能路径。本文中的 route 不是一个单一神经元，而是一组在答案生成附近有因果作用的 traced nodes。

**Answer-adjacent route**

答案生成附近的内部路径。也就是说，这些节点的作用被测量在模型即将输出目标答案 token 的位置附近。

**Source node**

通过 tracing / attribution 找到的候选机制节点。它们是我们认为可能参与答案生成路径的节点。

**Matched control / nearest control**

对照节点。为了排除“随便找一个同层同位置附近 feature 也会有效”的可能，我们找相似但不是 traced source 的节点作为对照。`nearest control` 是最接近 source 的非 source feature。

**Random control**

随机对照。本文中有两种：

- 随机节点对照：随机选择非 source feature；
- 随机区域对照：遮挡与 answer mask 同面积、但尽量不重叠的图片区域。

**Support node / support route**

清零该节点后，目标答案 logit 下降，说明该节点原本在支持目标答案。我们称其为 support。

**Suppressor node / suppressor route**

清零该节点后，目标答案 logit 上升，说明该节点原本在压制目标答案或支持竞争答案。我们称其为 suppressor。

**Signed causal route**

带方向的因果路径。signed 指同一批 traced nodes 里既有 support，也有 suppressor，不是所有节点都单向支持正确答案。

**Intervention / zeroing**

干预。这里主要指把某个内部 feature node 的激活清零，然后看目标答案 logit / rank / generation 是否改变。

**Wrong image**

错图条件。把原问题配上另一张不匹配的图片，用来测试内部路径是否依赖图像内容。

**Masked image**

粗遮挡条件。通常遮掉图片中心或固定比例区域，用来测试图像破坏对 route 的影响。

**No image**

无图条件。用灰图或空图替代原图。这个条件很强，但解释复杂，目前不进入 strongest evidence。

**Answer mask**

人工标注的最小答案证据区域。例如问题问“这个孩子几岁”，answer mask 会框住孩子本体。

**Relate mask**

人工标注的相关支持区域。它不是最小答案区域，而是上下文或第二支持证据。

**Union mask**

`answer mask ∪ relate mask`，即 answer 和 relate 的并集遮挡。

**Evidence-region-sensitive**

证据区域敏感。指遮挡人工标注的答案证据区域时，内部 route effect 明显变弱，并且强于随机同面积区域遮挡。

**Bootstrap CI**

Bootstrap confidence interval，自助法置信区间。这里用来估计均值是否稳定为正。如果 95% CI 不跨 0，通常表示方向较稳。

**Restoration**

恢复实验。把 corrupted condition 下的某些 clean activation patch 回去，看能否恢复目标答案。我们做过 single-node 和 multi-node restoration，但目前它不是主证据。

## 1. 我们一开始想证明什么

项目早期的直觉是：

> Prompt A 让模型更依赖图像，Prompt B 更像直接靠语言先验回答。

换句话说，我们本来想证明：

> 加上 “step-by-step” 和 “from visual evidence” 这样的提示后，VLM 会更视觉 grounded，内部 graph / circuit 会和直接回答 prompt 不一样。

这个目标可以拆成三层：

1. 行为层：Prompt A 是否让答案更好、更依赖图像；
2. 图结构层：Prompt A/B 的 traced graph 是否不同；
3. 机制层：Prompt A/B 是否真的改变模型内部使用视觉证据的方式。

早期我们最关注的是 A/B graph difference，也就是：

> 两个 prompt 的 graph overlap、top path、feature node 是否明显不同。

但后来发现，这个原始目标太粗，也不够严谨。

---

## 2. 为什么原始目标需要降调

### 2.1 Prompt A/B 有严重 confound

Prompt A 不只是加了 visual evidence，它还加了 step-by-step。也就是说，Prompt A 同时改变了两个因素：

```text
Prompt A = step-by-step + visual evidence
Prompt B = direct answer
```

所以如果看到 A/B 不同，我们不能直接说：

> 差异来自 visual grounding。

更严谨地说，只能说：

> 原始 A/B 差异混合了视觉证据提示、推理风格、输出格式、语言分布等因素。

因此，后续主对照转向更干净的：

```text
B_direct vs D_visual_only
```

`D_visual_only` 只加 visual evidence instruction，不加 step-by-step。这样才能更接近“视觉证据提示是否改变 route”这个问题。

### 2.2 Graph difference 本身不是机制结论

早期 graph compare 有价值，但不能直接当机制证明。原因是：

1. graph compare 是 observational，不是 causal；
2. 早期还有 target token mismatch 问题；
3. raw `.pt` graph 有时退化，不够 faithful；
4. graph overlap 只能提供候选节点，不能证明节点真的影响答案。

因此，项目主线从：

```text
证明 A/B graph 不一样
```

转向：

```text
用 causal intervention 证明 answer-adjacent routes 的功能
```

### 2.3 “Prompt 更好”不是当前数据支持的主结论

最近实验已经削弱了一个强说法：

> `D_visual_only` 比 `B_direct` 更好。

目前数据更支持：

> `B_direct` 和 `D_visual_only` 都能暴露 evidence-sensitive answer routes；prompt 是 route modulation variable，而不是谁更优的简单比较。

因此，我们不再把主目标写成：

> visual evidence prompt improves VQA.

而是写成：

> visual evidence / prompt variation helps probe how VLM internally uses visual evidence.

## 3. 现在主目标变成了什么

现在最稳的研究问题是：

> 多模态问答模型在生成答案时，内部是否存在可因果识别、带方向、对图像证据敏感的 answer-adjacent routes？

更具体地说：

1. 是否存在 support routes 和 suppressor routes；
2. support routes 是否对图像破坏敏感；
3. 这种敏感性是否强于 matched controls；
4. 这种 route 变化是否能解释 target rank / margin / decoded answer 的变化；
5. prompt 是否改变或暴露这些 route，而不是简单提升准确率。

当前主 claim 可以写成：

> 在 localized、strong image-dependence 的 VQA 样本中，VLM 答案生成附近存在可因果识别的 signed routes；其中 traced support routes 对 wrong-image 和 evidence-region mask 敏感，并且这种敏感性强于 matched non-source controls。区域遮挡还会改变 decoded answers，说明它不只是 target logit 层面的数值现象。

中文版本：

> 在强视觉依赖且证据区域可定位的视觉问答样本中，模型答案生成附近存在带方向的内部因果路径；其中支持目标答案的路径会被错图和关键证据区域遮挡削弱，这种削弱强于匹配对照节点和随机区域对照，并且会反映到答案排名、margin 和最终生成答案上。

---

## 4. 现在实验实际发现了什么

### 4.1 Signed causal routes 存在

在 alignment-clean pack10 上，我们做了 node-level zeroing。10 个样本中有 40 条成功 intervention，出现了两类方向：

- support：清零后 target logit 下降；
- suppressor：清零后 target logit 上升。

这说明 traced nodes 不是统一支持答案，而是 mixed-sign。

能说明：

> answer-adjacent route 是 signed / heterogeneous 的，不能把 top path node 简单理解成“答案支持节点”。

不能说明：

> 每个节点都对应一个明确物体或语义概念。

### 4.2 Support routes 对 wrong image 敏感

在 modality counterfactual 中，我们比较了：

```text
clean / masked_image / wrong_image / no_image
```

结果显示：

- support nodes 在 `wrong_image` 下明显变弱；
- suppressor nodes 更 sign-stable，但也有复杂变化；
- support 的 source-control gap 在 wrong_image 下会缩小；
- suppressor 的 gap 仍较大。

能说明：

> support route 的因果作用依赖图像条件，不只是语言 prompt artifact。

不能说明：

> 这些 feature 就是 object detector。

### 4.3 Source nodes 强于 matched controls

nearest matched control 显示，traced source nodes 的效果强于附近 non-source features。

能说明：

> tracing 找到的 source nodes 不是随便找一个相似 feature 就能替代。

这让 causal intervention 的可信度明显高于 raw graph compare。

### 4.4 Evidence-region sensitivity 成立

后续我们把 wrong-image 敏感推进到更局部的 evidence-region mask。

在 core24 prefix-fixed region experiment 中：

- 完整标注样本：22；
- source-overlap sample ids：10；
- nearest-control-overlap sample ids：8；
- manifest rows：46；
- support source rows：13；
- support nearest-control rows：9；
- suppressor source rows：14；
- suppressor nearest-control rows：10。

关键 prefix fix 后，clean calibration exact match：

```text
mean_abs_error = 0
max_abs_error = 0
exact_match_rate = 1.0
```

这说明 region 脚本和原 answer-aligned intervention pipeline 对齐。

主结果：

```text
support source answer-mask weakening
mean = +0.601
95% CI = [+0.313, +0.914]
positive rate = 0.846
n = 13

support source union-mask weakening
mean = +0.649
95% CI = [+0.351, +0.962]
positive rate = 0.846
n = 13
```

source vs nearest：

```text
source-minus-nearest answer weakening
mean = +0.861
95% CI = [+0.250, +1.597]

source-minus-nearest union weakening
mean = +0.924
95% CI = [+0.257, +1.729]
```

能说明：

> support source routes 对人工标注的答案证据区域敏感，并且这种敏感性强于 nearest non-source controls。

### 4.5 Random4 和 random16 都支持 specificity

随机区域对照用于排除：

> 是不是随便遮同样大小区域都会削弱 route？

random4 结果：

```text
support source answer minus random4
mean = +0.431
95% CI = [+0.052, +0.868]

support source union minus random4
mean = +0.472
95% CI = [+0.094, +0.910]
```

random16 结果：

```text
support source answer minus random16
mean = +0.423
95% CI = [+0.058, +0.828]

support source union minus random16
mean = +0.464
95% CI = [+0.112, +0.868]
```

能说明：

> answer/union mask 的 effect 强于更大的随机区域池，不是 random4 太少造成的假阳性。

保守 caveat：

> valid random-control coverage 不均匀，分析必须过滤 high-IoU random masks。

### 4.6 Region masks 改变 decoded answers

我们补了 generation-side check。

结果：

```text
B_direct answer_mask: 6/10 changed
B_direct union_mask: 8/10 changed
B_direct random4_valid: 4/22 changed

D_visual_only answer_mask: 7/9 changed
D_visual_only union_mask: 6/9 changed
D_visual_only random4_valid: 6/21 changed
```

同时：

```text
format_prefix_ok = 100%
empty/error = 0
```

能说明：

> evidence-region mask 不只是改变内部数值，也会更频繁改变最终短答案，并且不是输出格式崩坏导致的。

不能说明：

> node intervention 已经直接改变 decoded generation。

因为 node-generation smoke 目前被 `feature_intervention_generate` 的 multimodal batch 接口限制挡住。

### 4.7 Typed analysis 显示机制集中在 compact evidence cases

类型切分结果：

```text
symbol_text_reading:
answer weakening mean = +0.646
answer changed rate under answer mask = 0.700

visual_readout:
answer weakening mean = +0.763
answer changed rate under answer mask = 0.714

scene_inference:
answer weakening mean = +0.063
underpowered / heterogeneous
```

能说明：

> evidence-region sensitivity 最清楚地出现在证据区域紧凑、可定位的文字/符号读取和视觉读出样本。

不能说明：

> 所有 VQA 类型都共享同一种机制。

### 4.8 Suppressor routes 也有 secondary signal

suppressor source weakening：

```text
answer mask mean = +0.866
95% CI = [+0.406, +1.375]

union mask mean = +1.036
95% CI = [+0.527, +1.638]
```

suppressor source-minus-nearest：

```text
answer mask mean = +0.481
95% CI = [+0.019, +1.025]

union mask mean = +0.563
95% CI = [+0.113, +1.100]
```

能说明：

> answer-adjacent route 不只有 support，也包含 suppressive / competitive components。

但 suppressor 更复杂，所以作为 secondary，不作为主 claim。

### 4.9 Restoration 线需要降级

single-node restoration 遇到严重 alignment bottleneck：

```text
32 unique nodes 中只有 10 个 restoration-ready
10 个 ready nodes 全是 support
suppressor ready = 0
restore_minus_corrupt 接近 0
restore_minus_zero 通常为正
```

multi-node restoration 有 case-level positive：

```text
okvqa_val_00558
两个 2-node groups
restore_minus_corrupt = +0.125
restore_minus_zero > 0
```

能说明：

> distributed support route 有可能存在。

不能说明：

> restoration 已经证明 route 可恢复。

因此 restoration 只适合作为 supporting case study。

## 5. 现在能说明什么

### 5.1 内部确实存在 answer-adjacent causal routes

我们可以说：

> VLM 回答问题时，不只是输出文本不同；答案生成附近存在可被 traced、可被 zeroing 干预、带方向的内部路径。

证据：

- signed node-level intervention；
- support / suppressor 同时存在；
- source nodes 强于 matched controls。

### 5.2 Support routes 对图像证据敏感

我们可以说：

> traced support routes 不只对 whole-image corruption 敏感，也对人工标注的 answer evidence region 敏感。

证据：

- wrong_image 下 support weakening；
- answer/union mask 下 support weakening；
- answer/union mask 强于 random4 和 random16；
- source 强于 nearest controls。

### 5.3 这种内部变化和行为变化有关

我们可以说：

> evidence-region masking 不只改变内部 route effect，也会改变 target rank / margin / decoded answer。

证据：

- target rank 和 margin directionally consistent；
- answer/union mask 比 random controls 更常改变 decoded answer；
- format_prefix_ok 100%，empty/error 0。

### 5.4 机制不是所有类型一刀切

我们可以说：

> 该机制在 compact evidence cases 中最清楚，尤其是 symbol_text_reading 和 visual_readout。

证据：

- typed summary；
- `okvqa_val_02444`；
- `okvqa_val_4739195`；
- `okvqa_val_1729795`。

## 6. 现在不能说明什么

### 6.1 不能说 `D_visual_only` 比 `B_direct` 更好

当前证据不支持这个强说法。

更准确：

> `B_direct` 和 `D_visual_only` 都暴露 evidence-sensitive routes；prompt 差异是 modulation，不是 superiority。

### 6.2 不能说某个 node 就是某个 object node

现在证明的是：

> route 对 evidence region 敏感。

还不能证明：

> feature 本身编码某个物体、文字、颜色或语义概念。

要证明 object-level semantics，需要 feature interpretation、region/object intervention、activation visualization 等额外证据。

### 6.3 不能说 restoration 是主证据

restoration 目前受 alignment bottleneck 限制，样本太少、ready subset 偏 support。

### 6.4 不能说所有 VQA 类型都成立

目前最强的是 localized strong image-dependence cases。scene inference、entity linking、diffuse/global evidence 还不能强推。

### 6.5 不能说 node intervention 已经直接改变 natural generation

我们已有：

```text
region mask -> route weakening
region mask -> decoded answer changes
```

但还没有：

```text
node intervention -> decoded answer changes
```

node-generation smoke 被当前接口限制挡住。

---

## 7. 当前最稳的最终表述

推荐主结论：

> 本项目不再试图证明某个 visual-evidence prompt 在行为上稳定优于 direct prompt。相反，我们证明：在 localized、strong image-dependence 的视觉问答样本中，VLM 答案生成附近存在可因果识别的 signed routes。其中 traced support routes 对 wrong-image corruption 和 annotated evidence-region masking 都敏感；answer/union evidence masks 对 support source routes 的削弱强于 same-area random controls，包括 random16，并且强于 nearest matched non-source controls。区域遮挡还会更频繁改变 decoded answers，而不是只改变内部 logit。因此，当前最强结论是：VLM 内部存在与视觉证据相关的答案支持路径和更复杂的竞争/抑制路径；prompt 的作用是调节或暴露这些路径，而不是简单让模型更好。

---

## 8. 一句话总结

过去我们想证明：

> Prompt A / visual-evidence prompt 更 grounded。

现在实验真正支持的是：

> 多模态模型内部存在可干预、带方向、对图像证据区域敏感的答案路径；这些路径的变化能部分解释 target rank、margin 和最终答案变化。
