## 0. 报告摘要

本项目最初试图证明：

> visual-evidence prompt 或 Prompt A 会让 VLM 更视觉 grounded。

但经过 prompt factorization、causal intervention、matched controls、modality corruption 和 evidence-region mask 等一系列实验后，当前更严谨的结论应当是：

> 在 localized、strong image-dependence 的视觉问答样本中，VLM 答案生成附近存在可因果识别的 signed answer-adjacent routes。其中 support routes 对 wrong-image corruption 和 annotated evidence-region masking 都敏感，并且 traced source nodes 的敏感性强于 nearest matched non-source controls 和 same-area random region controls。区域遮挡还会改变 decoded answers，说明这些内部 route 与最终回答行为有关。

中文简化：

> 模型不是简单“看图或不看图”，而是在答案附近使用一组带方向的内部路径：有些路径支持目标答案，有些路径压制或竞争目标答案。支持路径会被错图和关键证据区域遮挡削弱，这种削弱不是随机遮挡或普通相似节点能解释的，并且会反映到答案排名和最终回答变化上。

当前不应再把主目标写成：

> `D_visual_only` 比 `B_direct` 更好。

更应该写成：

> prompt 是调节或暴露内部视觉证据路径的变量，而不是行为优劣比较的主角。

## 1. 专有名词解释

**VLM**

视觉-语言模型，能同时处理图片和文本问题。

**Route**

内部路径。本文指模型在生成答案 token 附近，一组对答案有因果影响的 feature nodes。

**Answer-adjacent**

答案附近。不是解释整个模型所有行为，而是解释模型即将输出目标答案 token 时附近的内部机制。

**Support route**

支持路径。清零这些节点后，目标答案 logit 下降，说明它们原本支持目标答案。

**Suppressor route**

抑制路径。清零这些节点后，目标答案 logit 上升，说明它们原本压制目标答案或支持竞争答案。

**Signed route**

带方向的路径。说明内部节点不是全都支持正确答案，而是有正向和负向作用。

**Source node**

通过 tracing 找到的候选机制节点。

**Nearest control**

与 source node 同层、同位置或相似的非 source feature，用于对照。

**Random region control**

随机区域遮挡对照。遮挡与 answer mask 同面积、但尽量不重叠的区域。

**Answer mask**

人工标注的最小答案证据区域。

**Relate mask**

人工标注的相关上下文区域。

**Union mask**

answer 和 relate 的并集。

**Evidence-region-sensitive**

关键证据区域敏感。遮挡答案证据区域会削弱内部 route effect，并且强于随机区域遮挡。

**Decoded answer**

模型最终生成出来的文本答案，而不是单个 target token 的 logit。

## 2. 当前能证明的核心结论

### 2.1 结论一：答案附近存在 signed causal routes

我们能证明：

> VLM 答案生成附近存在可被干预的内部路径，而且这些路径有方向：有 support，也有 suppressor。

支持证据：

- alignment-clean pack10 中，10 个样本产生 40 条成功 node intervention；
- 清零不同节点后，有的让 target logit 下降，有的让 target logit 上升；
- 说明 traced nodes 是 mixed-sign，不是统一答案支持节点。

意义：

> 视觉问答模型内部的答案生成机制不是单一路径，也不是所有 top nodes 都支持答案，而是包含支持和竞争/抑制成分。

限制：

> 这只能说明节点有因果方向，不能说明节点语义是什么。

### 2.2 结论二：support routes 对图像破坏敏感

我们能证明：

> Support routes 会受到 wrong_image 等图像条件破坏影响。

支持证据：

- modality counterfactual 使用 `clean / masked_image / wrong_image / no_image`；
- support nodes 在 wrong_image 下明显变弱；
- suppressor 更 sign-stable，但也有复杂变化；
- wrong_image 是早期最强多模态机制证据。

意义：

> support route 不是纯语言路径；它依赖图像条件。

限制：

> wrong_image 是整图级破坏，不能直接说明 route 对关键视觉证据区域敏感。

### 2.3 结论三：source nodes 强于 matched controls

我们能证明：

> traced source nodes 的效果强于 matched non-source controls。

支持证据：

- nearest matched control；
- source-control gap；
- wrong_image 下 support source-control gap 有系统变化；
- region mask 下 source-minus-nearest answer / union weakening 均为正。

core24 关键数值：

```text
source-minus-nearest answer weakening:
mean = +0.861
95% CI = [+0.250, +1.597]

source-minus-nearest union weakening:
mean = +0.924
95% CI = [+0.257, +1.729]
```

意义：

> tracing 找到的节点不是任意附近 feature 可替代，具有 source specificity。

限制：

> nearest control 不能覆盖所有可能对照，只能说明相似 non-source feature 不足以解释结果。

### 2.4 结论四：support routes 对人工标注的答案证据区域敏感

这是当前最重要的新结果。

我们能证明：

> 遮挡 answer mask / union mask 会稳定削弱 support source route。

core24 结果：

```text
support source answer-mask weakening:
mean = +0.601
95% CI = [+0.313, +0.914]
positive rate = 0.846
n = 13

support source union-mask weakening:
mean = +0.649
95% CI = [+0.351, +0.962]
positive rate = 0.846
n = 13
```

意义：

> 我们把结论从 image-corruption-sensitive 推进到了 evidence-region-sensitive。

限制：

> 这仍然不等于证明每个 feature 是 object-level semantic feature。

### 2.5 结论五：answer / union mask 强于 random region controls

我们能证明：

> evidence-region mask 的效果强于同面积随机区域遮挡。

random4：

```text
answer minus random4:
mean = +0.431
95% CI = [+0.052, +0.868]

union minus random4:
mean = +0.472
95% CI = [+0.094, +0.910]
```

random16：

```text
answer minus random16:
mean = +0.423
95% CI = [+0.058, +0.828]

union minus random16:
mean = +0.464
95% CI = [+0.112, +0.868]
```

意义：

> 不是遮任意同面积区域都会产生同样 route weakening；answer evidence region 更关键。

限制：

> random control coverage 不均匀，必须过滤高 IoU random masks。

### 2.6 结论六：区域遮挡会改变 decoded answers

我们能证明：

> evidence-region mask 不仅改变 target logit，也改变最终生成答案。

结果：

```text
B_direct:
answer_mask changed = 6/10
union_mask changed = 8/10
random4_valid changed = 4/22

D_visual_only:
answer_mask changed = 7/9
union_mask changed = 6/9
random4_valid changed = 6/21
```

同时：

```text
format_prefix_ok = 100%
empty/error = 0
```

意义：

> route / region effect 和最终行为有关，不只是内部数值现象。

限制：

> 当前还没有 node intervention 直接改变 decoded generation 的实验成功结果。

### 2.7 结论七：机制集中在 compact visual evidence cases

我们能证明：

> evidence-region sensitivity 在 symbol_text_reading 和 visual_readout 中最清楚。

结果：

```text
symbol_text_reading:
answer weakening mean = +0.646
answer changed rate = 0.700

visual_readout:
answer weakening mean = +0.763
answer changed rate = 0.714

scene_inference:
answer weakening mean = +0.063
underpowered / heterogeneous
```

意义：

> 多模态机制不是所有问题一刀切，必须按样本类型分析。

限制：

> scene inference / entity linking / diffuse global cases 仍需单独研究。

### 2.8 结论八：suppressor routes 也有 evidence sensitivity，但应降为 secondary

suppressor source：

```text
answer weakening mean = +0.866
95% CI = [+0.406, +1.375]

union weakening mean = +1.036
95% CI = [+0.527, +1.638]
```

source-minus-nearest：

```text
answer mean = +0.481
95% CI = [+0.019, +1.025]

union mean = +0.563
95% CI = [+0.113, +1.100]
```

意义：

> answer-adjacent routing 包含竞争/抑制路径，不只是 support route。

限制：

> suppressor 的因果解释更复杂，不能作为主论证支柱。

## 3. 当前最强证据链

目前最强证据链可以写成：

```text
traced source nodes exist
→ zeroing shows signed causal effects
→ support nodes weaken under wrong_image
→ source nodes beat nearest controls
→ answer/union evidence masks weaken support source nodes
→ answer/union masks beat random4 and random16
→ answer/union masks change decoded answers
→ effect strongest in compact symbol_text_reading / visual_readout
```

这条链条支持：

> VLM 在回答视觉问题时，内部确实存在与视觉证据相关的答案支持路径。

## 5. 当前主要缺陷

### 5.1 样本量仍然不大

core24 主分析中：

```text
support source rows = 13
support nearest rows = 9
source samples = 8-10
```

这足以支撑一个 strong pilot / focused mechanism result，但还不是大规模统计结论。

需要避免写成：

> 所有 VQA 样本都如此。

应写成：

> localized strong-image-dependence cases 中如此。

### 5.2 当前 replication 受限

已有额外 annotation packs 无法直接做 same-backbone replication，因为没有 current source/control overlap。

当前可直接补的 current-backbone candidates 很少：

```text
okvqa_val_299845
okvqa_val_3605295
```

要做真正 10-15 样本 replication，需要重新：

1. 选 current-backbone samples；
2. trace source nodes；
3. 构造 nearest controls；
4. 再做 annotation。

### 5.3 Prompt difference 不是主结果

`D_visual_only` 没有稳定优于 `B_direct`。

如果硬写：

> visual evidence prompt makes model better

会被结果反驳。

应写：

> prompt variation modulates or reveals route usage。

### 5.4 Object-level semantic interpretation 还不足

我们证明了：

> evidence-region-sensitive routes。

还没证明：

> node is dog detector / text detector / color detector。

要证明 object-level feature，需要：

- feature activation visualization；
- region-specific activation analysis；
- object-aware masks；
- counterfactual object insertion/removal；
- feature interpretation。

### 5.5 Node-to-generation direct bridge 未完成

我们有两条证据：

```text
region mask -> route weakening
region mask -> decoded answer changes
```

但缺少：

```text
node intervention -> decoded answer changes
```

node-generation smoke 因 `feature_intervention_generate` 不支持当前 multimodal batch path 而失败。

这不影响当前主 claim，但限制了更强的 causal behavior claim。

### 5.6 Restoration 不能作为主线

single-node restoration：

- restoration-ready yield 低；
- suppressor ready = 0；
- position_out_of_range 多；
- survivor bias 明显；
- restore_minus_corrupt 不强。

multi-node restoration：

- `okvqa_val_00558` 有 positive case；
- 但样本太少。

因此 restoration 只能作为 distributed route 的 supporting case。

## 6. 未来应该补什么

### 6.1 最优先：targeted replication pack

目标：

> 证明 core24 结果不是偶然。

设计：

1. 从 current backbone 或新 held-out pack 中选 10-15 个 localized cases；
2. 优先 `symbol_text_reading` 和 `visual_readout`；
3. 要求 strong image dependence；
4. 要求 support source + nearest control 可用；
5. 避免 diffuse / ambiguous / global scene cases；
6. 跑同样 prefix-fixed region pipeline；
7. 重复 answer/union vs random16、source vs nearest、decoded generation。

成功标准：

```text
support answer/union weakening > random controls
source > nearest
decoded answer changes > random controls
至少一个 type slice 复现
```

### 6.2 第二优先：node-to-generation engineering

目标：

> 让 node intervention 直接作用于 decoded generation。

需要：

- 自定义 greedy generation loop；
- multimodal batch hooks；
- first-token intervention；
- cache-compatible continuation；
- baseline vs zeroed source comparison。

如果成功，可获得更强结论：

> source node zeroing changes final answer。

### 6.3 第三优先：object / feature interpretation

目标：

> 从 evidence-region-sensitive 推进到 object-level semantic interpretation。

可能方法：

- feature activation heatmap；
- answer mask 内外 activation 对比；
- object detector / OCR region 对齐；
- region ablation curve；
- patch-level intervention；
- top activating images。

### 6.4 第四优先：suppressor deep case

目标：

> 找一个 suppressor 路径可解释的 case。

问题：

> suppressor 是压制错误答案，还是竞争答案路径？

需要：

- wrong answer token tracking；
- competitor logit；
- source suppressor zeroing；
- decoded answer effect；
- nearest controls。

### 6.5 第五优先：restoration 只做 case study

不要大规模扩 restoration，除非先解决：

- position alignment；
- corrupted condition tracing；
- semantic position mapping；
- suppressor ready = 0。

## 8. 建议最终主结论

长版本：

> 本工作研究多模态问答模型在生成答案时如何内部使用视觉证据。我们发现，在 localized、strong image-dependence 的 OK-VQA 样本中，答案生成附近存在可因果识别的 signed routes：部分节点支持目标答案，部分节点具有抑制或竞争作用。通过 node-level zeroing、wrong-image corruption、matched controls 和 evidence-region masking，我们发现 traced support routes 对图像证据破坏敏感。特别是，在 prefix-fixed core24 标注包中，遮挡人工标注的 answer / union evidence regions 会稳定削弱 support source effects，并且这种削弱强于 nearest matched non-source controls 和 same-area random controls，包括 random16。区域遮挡还更频繁改变 decoded answers，且没有 format collapse 或 empty-answer failure。因此，当前最强结论不是某个 prompt 更好，而是 VLM 内部存在可定位、可干预、对视觉证据区域敏感的答案支持路径，以及更复杂的抑制/竞争路径。

短版本：

> VLM 在回答视觉问题时，内部存在 signed answer-adjacent causal routes；其中 support routes 对错图和关键证据区域遮挡敏感，强于 matched controls 和 random controls，并且这些区域遮挡会影响最终生成答案。

## 9. 最后判断

当前项目已经从一组 prompt / graph pilot 收束成一个可讲的机制故事：

```text
不是证明哪个 prompt 更好，
而是证明模型如何内部使用视觉证据生成答案。
```

主线已经足够写成报告或论文结果段。

如果继续实验，最有价值的是：

1. targeted replication；
2. node-to-generation engineering；
3. object-level feature interpretation。

不建议继续把主要资源投入：

1. 证明 `D_visual_only > B_direct`；
2. 大规模 restoration；
3. diffuse/global evidence masks；
4. 无 target alignment 的 graph compare。
