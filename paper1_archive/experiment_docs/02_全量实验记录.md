# 02 全量实验记录

日期：2026-05-19

本文尽可能详细记录从早期 Prompt A/B graph compare，到后续 intervention、modality corruption、matched control、region mask、random16、generation eval、restoration 等所有主要实验线。

如果要找“某个结果到底来自哪里”，优先查本文。

---

## 0. 实验主线总览

项目从早期到现在，大致经历了以下阶段：

1. **Prompt A/B graph compare 阶段**：观察不同 prompt 的 graph 是否不同；
2. **Target control / alignment-clean 阶段**：修正 target token mismatch，构建可干预样本；
3. **Node-level intervention 阶段**：用 zeroing 判断 source nodes 是否有因果作用；
4. **Modality counterfactual 阶段**：比较 clean / wrong_image / masked_image / no_image；
5. **Matched control 阶段**：比较 traced source nodes 和 nearest/random controls；
6. **Prompt factorization 阶段**：从原始 A/B 转向 `B_direct vs D_visual_only`；
7. **Typed sample 阶段**：给样本打 image_dependence / reasoning_operation 等标签；
8. **Restoration 阶段**：尝试 single-node / multi-node patching；
9. **Evidence-region mask 阶段**：用人工 answer/relate mask 测试关键证据区域敏感性；
10. **Generation-side validation 阶段**：看 target rank / margin / decoded answer 是否变化；
11. **Random16 和附加验证阶段**：加强 random region specificity，检查 suppressor，尝试 node-generation smoke。

当前主线是第 9-11 阶段形成的：

```text
intervention
→ modality corruption
→ matched control
→ evidence-region mask
→ random controls
→ generation behavior linkage
```

## 1. Prompt A/B graph compare

### 1.1 实验目的

早期问题：

> Prompt A 和 Prompt B 是否让模型使用不同内部 graph / circuit？

其中：

- Prompt A：通常包含 step-by-step 和 visual evidence；
- Prompt B：直接回答。

早期直觉：

> Prompt A 更 visual grounded，因此内部 graph 应该和 Prompt B 不一样。

### 1.2 方法

对同一批 OK-VQA 样本，用不同 prompt 跑 circuit tracing，比较：

- graph overlap；
- top path；
- top nodes；
- graph 中 feature 的层、位置、权重；
- A/B graph 差异。

### 1.3 发现

早期确实能看到 A/B graph difference，但问题很多：

1. target token 可能不一致；
2. Prompt A/B 同时改变了多个因素；
3. raw graph compare 是 observational，不是 causal；
4. graph overlap 不稳定，有时 `.pt` compare 退化；
5. graph difference 只能提供候选节点，不能证明机制差异。

### 1.4 结论

graph compare 的价值：

> 发现现象、提供候选节点、指导后续 intervention。

graph compare 不能作为主结论：

> 不能仅凭 graph difference 说模型真的用了不同机制。

## 2. Prompt factorization

### 2.1 实验目的

修正原始 A/B prompt confound。

原始 Prompt A 同时包含：

```text
step-by-step
from visual evidence
```

所以需要拆成：

- `B_direct`：直接回答；
- `D_visual_only`：只加 visual evidence；
- `C_step_only`：只加 step-by-step；
- `A_step_visual`：step-by-step + visual evidence。

### 2.2 方法

对同一批样本，比较不同 prompt 家族：

- 行为输出；
- target rank；
- graph / traced nodes；
- intervention effect；
- modality corruption effect。

### 2.3 发现

关键发现：

> `D_visual_only` 并没有稳定表现为比 `B_direct` 更好。

这说明原始 A/B 不能被解释为：

> A 更视觉 grounded。

更稳的解释：

> prompt 改变或暴露 answer-adjacent routes，但不稳定提升行为准确率。

### 2.4 结论

主 claim 从：

```text
visual-evidence prompt is better
```

改成：

```text
prompt variation probes route modulation
```

## 3. Target control 和 alignment-clean pack

### 3.1 实验目的

解决早期 target token mismatch 问题。

如果 A/B 输出的答案 token 不同，直接比较 graph 或 logit 会混入目标变化。

### 3.2 方法

构建 alignment-clean subset，要求：

- target token metadata complete；
- answer prefix 可定位；
- target token / answer position 对齐；
- clean condition 可复现；
- feature layer / position / id 完整。

### 3.3 发现

alignment-clean subset 使后续 intervention 能稳定运行，也暴露了 restoration 的 position alignment 问题。

### 3.4 结论

后续主实验必须基于 answer-aligned / prefix-fixed / metadata-complete rows。

---

## 4. Node-level zeroing intervention

### 4.1 实验目的

判断 traced source nodes 是否真的对答案有因果作用。

问题：

> 清零 traced node 后，目标答案 logit 是否改变？

### 4.2 方法

对 source node 做 zeroing：

```text
feature activation -> 0
```

记录：

- original target logit；
- intervened target logit；
- delta target logit；
- target probability；
- top1 before / after；
- support / suppressor sign。

### 4.3 数据

alignment-clean pack10：

- 10 个样本；
- 40 条成功 intervention；
- 同时出现 support 和 suppressor。

### 4.4 结果

发现 mixed-sign causal effects：

- support：清零后 target logit 下降；
- suppressor：清零后 target logit 上升。

### 4.5 结论

可以说明：

> traced nodes 不是统一支持答案，而是 signed heterogeneous routes。

不能说明：

> support/suppressor 对应明确语义 object。

---

## 5. Modality counterfactual

### 5.1 实验目的

测试 route 是否依赖图像。

问题：

> 如果换错图、遮图、无图，support/suppressor 的 intervention effect 是否改变？

### 5.2 条件

```text
clean
masked_image
wrong_image
no_image
```

### 5.3 方法

对同一 source node，在不同图像条件下做 zeroing，比较 delta target logit。

### 5.4 结果

主要观察：

- support nodes 在 wrong_image 下明显变弱；
- suppressor nodes 更 sign-stable；
- wrong_image 是最强的多模态证据；
- no_image 解释复杂，后续降级。

### 5.5 结论

可以说明：

> support route 对图像条件敏感。

不能说明：

> route 一定是 object-level visual semantic node。

---

## 6. Matched control 实验

### 6.1 实验目的

排除：

> 是不是同层同位置附近任意 feature 都会有类似 effect？

### 6.2 对照类型

- nearest matched non-source control；
- random matched control；
- later random4/random16 region controls。

### 6.3 方法

对 source nodes 和 control nodes 跑同样的 intervention / modality condition。

比较：

```text
source effect
control effect
source-control gap
```

### 6.4 结果

主要发现：

- traced source nodes 强于 nearest controls；
- support source-control gap 在 wrong_image 下缩小；
- suppressor source-control gap 仍较大；
- matched controls 使主结论明显更可信。

### 6.5 结论

可以说明：

> source nodes 不是随便找 nearby feature 就能替代。

---

## 7. Visual-positive strong12 / strong18 主实验

### 7.1 实验目的

从 pilot 扩展到更明确的 visual-positive backbone。

主要问题：

> 在 held-out / current-mainline visual-positive samples 上，B/D 是否都存在 signed causal routes，且 support routes 是否对图像破坏敏感？

### 7.2 数据

主要使用：

- `strong12_corrected`；
- `strong18_next`；
- clean-core usable rows；
- support/suppressor source nodes；
- nearest controls。

### 7.3 方法

跑：

- clean intervention；
- wrong_image / masked_image / no_image；
- matched controls；
- target rank / margin；
- generation-side behavior summary；
- typed summary。

### 7.4 结果

主结果：

- support source nodes under wrong_image still beat controls；
- nearest 和 random controls 都支持 source specificity；
- D vs B 的增量差异弱；
- no_image，尤其 `D_visual_only + no_image`，降级；
- prompt-increment partial；
- main success 是 route existence + image sensitivity + controls。

### 7.5 结论

这轮把主 claim 固定为：

> signed causal routes 存在；support routes image-sensitive；source nodes beat controls；prompt increment 不是主结论。

## 9. Restoration 实验

### 9.1 实验目的

测试 corrupted condition 下，能否把 clean activation patch 回去恢复答案。

如果成功，可以证明：

> route 不只是被破坏，还能被恢复。

### 9.2 Single-node restoration

#### 数据

- 32 unique nodes；
- 10 restoration-ready；
- 10 个 ready nodes 全是 support；
- suppressor ready = 0。

#### 结果

- restore_minus_corrupt 接近 0；
- restore_minus_zero 通常为正；
- position_out_of_range 严重；
- survivor bias 明显。

#### 结论

single-node restoration 不足以构成主证据。

### 9.3 Multi-node restoration

#### 数据

最干净 positive case：

```text
okvqa_val_00558
```

generic filtering 后剩：

- A/B 两个 2-node groups；
- restore_minus_corrupt = +0.125；
- restore_minus_zero > 0。

#### 结论

可作为：

> distributed support route 的 case-level hint。

不能作为：

> restoration 证明 route 可恢复。

## 10. 人工 evidence-region 标注

### 10.1 实验目的

把 wrong-image sensitivity 推进到 evidence-region sensitivity。

问题：

> source route 是否对关键答案证据区域更敏感，而不是只对整图破坏敏感？

### 10.2 标注类型

只使用两类人工区域：

- `answer`：最直接、最小答案证据区域；
- `relate`：更宽的相关支持区域或上下文。

多个 answer 标注代表多个答案证据区域，分析时取 union。

### 10.3 标注包

主要包：

```text
okvqa_evidence_labelme_round4_core24_easy
```

其他包：

- round2 / round3：早期方法回归；
- route7：prefix-fixed regression / heterogeneous discovery；
- ultraeasy16_fresh / core16_extra：后来发现和 current backbone 无 source/control overlap；
- mainline16 / ultraeasy20：本地资产不完整或未进入同一 pipeline。

### 10.4 标注经验

有效样本应该优先：

- localized；
- answer region compact；
- visual_readout / symbol_text_reading；
- strong image dependence；
- clean answer rank 较好；
- support source + nearest control 可用。

不适合：

- diffuse global tint；
- terrain / scene gist；
- entity linking 过强；
- ambiguous / multi-answer。

## 20. Node-generation smoke

### 20.1 目的

测试：

> 是否能在 decoded generation 过程中同时做 node zeroing，从而直接证明 node intervention 改变最终生成答案？

### 20.2 方法

写了：

```text
run_region_mask_node_generation_smoke.py
```

目标：

```text
sample = okvqa_val_02444
node_role = support
node_source = source
conditions = clean, answer_mask, union_mask
```

### 20.3 结果

第一次失败：

```text
ModuleNotFoundError: circuit_tracer
```

修复：

```text
PYTHONPATH=/root/autodl-tmp/tca-reasoning/circuit_tracer_vlm
```

第二次：

- 模型加载成功；
- rows 选中；
- 所有 generation conditions 返回 `AssertionError`。

### 20.4 解释

问题在 `feature_intervention_generate` 和 multimodal batch path 的接口不匹配。

这不是机制结果失败，而是工程限制。

### 20.5 结论

当前不能 claim：

> node intervention directly changes decoded generation。

需要未来写 custom generation loop。

## 22. 全量实验结论

按证据强度排序：

### 最强

1. support source routes under answer/union masks weaken；
2. support source > nearest controls；
3. answer/union masks > random4；
4. answer/union masks > random16；
5. answer/union masks change decoded answers more often than random controls；
6. format collapse / empty output 被排除。

### 中等

1. suppressor evidence-region sensitivity；
2. typed concentration in symbol_text_reading / visual_readout；
3. route weakening correlates with margin drop；
4. `okvqa_val_02444` case figure。

### 弱 / 降级

1. D > B prompt increment；
2. restoration；
3. node-to-generation direct intervention；
4. diffuse scene inference；
5. object-level semantic interpretation。

## 23. 最终实验读法

所有实验合起来支持：

> VLM 回答视觉问题时，答案生成附近存在 signed causal routes。这些 routes 中，support routes 对错图和人工答案证据区域遮挡都敏感，并且 source nodes 的敏感性强于 nearest controls 和 same-area random controls。区域遮挡会影响 target rank / margin / decoded answer。prompt 不是简单让模型更好，而是调节或暴露这些内部路径。
