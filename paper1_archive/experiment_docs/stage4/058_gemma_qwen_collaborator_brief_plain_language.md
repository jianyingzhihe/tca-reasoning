# Gemma/Qwen 机制结果：给合作者讲的短版

更新时间：2026-05-28

## 最核心结论

我们要讲的不是某个资产、某个 layer、某个 feature id，而是这个结论：

```text
视觉语言模型回答图像问题时，内部确实存在“从图像证据到答案”的因果通路。
```

现在的结果分两层：

```text
Gemma：这条通路已经能被我们比较清楚地画出来、剪断、验证。

Qwen：这条通路也存在，但不像 Gemma 那样表现成一条稀疏、容易画图的 feature 路线；它更像藏在更整体、更分布式的 hidden 表示里。
```

一句适合对外讲的话：

```text
Gemma 给了我们一条清楚可追踪的“证据到答案”路线图；Qwen 说明类似的因果流不是 Gemma 特例，但不同模型可能用不同内部表示承载这条路线。
```

## 这说明了什么

第一，它说明我们不是只在做相关性。

我们不是只看“遮住图片以后答案变了”，而是进一步问：

```text
模型内部哪些地方跟着变？
把这些内部位置剪掉，答案会不会受伤？
把它们补回来，答案会不会恢复？
```

这就是因果证据，不只是现象观察。

第二，它说明这个机制不是 Gemma 独有。

Gemma 是目前证据最完整的模型，因为我们能画出路线图。  
Qwen 虽然还没画出同样清楚的稀疏路线图，但 hidden 层上的因果流很强，说明类似“看证据、传到答案”的过程也在 Qwen 里出现。

第三，它说明不同模型的机制可能“同目标、不同实现”。

类比一下：

```text
Gemma 像一台线路清楚的老式电路板：哪根线连到哪盏灯，我们能比较清楚地追出来。

Qwen 像一块高度集成芯片：功能也在，但不是几根裸露电线能解释完，信号可能分布在更整体的内部表示里。
```

所以 Qwen 不是“没机制”，而是“这个机制没有被当前 PLT 稀疏节点图完整展开”。

## 对论文主线的意义

这个结果对主线是正面的，但要讲得准确：

```text
我们已经在 Gemma 上建立了完整主链。
Qwen 提供跨模型支持：同类 evidence-to-answer 因果流存在。
但 Qwen 不是 Gemma 的一比一复刻，而是提示机制具有表示异质性。
```

最重要的科学含义是：

```text
多模态模型可能普遍存在“证据区域 -> 内部表示 -> 答案”的因果过程；
但这个过程在不同模型中未必表现为同一种可解释结构。
```

这比“Qwen 完全复现 Gemma”其实更有意思：

```text
如果所有模型都一模一样，只是复现。
现在看到的是：目标机制相似，但内部承载方式不同。
这可以发展成 mechanism heterogeneity，也就是机制异质性。
```

## 现在可以说什么

可以说：

```text
1. Gemma 上，我们已经有完整证据链支持图像证据区域会通过内部 source-tracing route 影响答案。

2. Qwen 上，我们也验证到稳定的 evidence-to-answer 因果流，尤其在 hidden 层非常强。

3. Qwen 的这条流没有被当前公开 Qwen-PLT 拆成像 Gemma 那样的少数稀疏节点，说明不同模型的机制表示方式可能不同。

4. 因此，这个现象不是 Gemma-only，但跨模型时不能假设所有模型都有同一张路线图。
```

## 现在不能说什么

不能说：

```text
Qwen 完全复现了 Gemma-style source tracing。
```

因为 Qwen 还没有通过完整的自动路线图、source/control、mask control、wrong target、rank/sequence 全链条。

也不能说：

```text
Qwen 没有这个机制。
```

因为 Qwen hidden 层的因果证据很强。

更准确的边界是：

```text
Qwen 有 evidence-to-answer 因果流；
但当前 Qwen-PLT 没有把它定位成 Gemma 那样的稀疏可追踪路线。
```

## 30 秒口播版

```text
我们的核心发现是：模型回答图像问题时，内部不是黑箱乱猜，而是有一条从图像证据区域到答案的因果链。

在 Gemma 上，这条链已经能被我们画出来，并且通过遮图、剪节点、做 controls 验证。

在 Qwen 上，类似的因果流也存在，而且 hidden 层证据很强；但它不像 Gemma 那样被当前 PLT 表示成少数清楚的稀疏节点。

所以结论不是“Qwen 复刻了 Gemma”，也不是“Qwen 没有机制”，而是：这个 evidence-to-answer 机制可能跨模型存在，但不同模型用不同内部表示来承载。
```

## 2 分钟解释版

```text
我们想证明的不是模型答对了，而是它为什么答。

具体说，我们标出图像里真正支持答案的区域，然后遮掉它，看模型内部和答案怎么变。接着我们不只看输出，还去模型内部找哪些节点或表示跟这个证据区域有关，再把这些内部位置剪掉或补回来，测试答案是否受影响。

Gemma 的结果最完整：我们能追出一张从证据到答案的路线图，并且路线上的节点干预后确实影响答案。这说明 Gemma 里有一条比较稀疏、可解释的 evidence-to-answer route。

Qwen 的结果不一样。Qwen 也有很强的 evidence-to-answer 因果流，特别是在 hidden layer 14 上，primary 和 strict 都复现了。但当我们试图用公开 Qwen-PLT 把这条流拆成少数 feature 节点时，它没有像 Gemma 那样闭合成一条稀疏路线。进一步测试显示，主要效果可能留在 reconstruction error 或更整体的 hidden residual 里。

所以这个结果的意义是：机制本身不是 Gemma 特例，但机制的可解释形态因模型而异。Gemma 是 sparse route 成功案例，Qwen 是 hidden-level route 成功、sparse PLT localization 尚未成功的案例。
```

## 如果被问“这对主结论是加强还是削弱”

回答：

```text
加强，但不是以“Qwen 完全复制 Gemma”的方式加强。
```

它加强的是：

```text
evidence-to-answer 因果流可能是跨模型现象。
```

它没有加强的是：

```text
所有模型都有同一条稀疏 feature route。
```

更准确地说：

```text
主机制更像跨模型存在；
具体可解释表示则是模型依赖的。
```

## 如果被问“为什么 Qwen 没画出路线图”

回答：

```text
目前更像是表示方式问题，而不是机制不存在。
```

原因：

```text
Qwen hidden 层因果流很强；
Qwen-PLT 里也有很多证据敏感节点；
也能找到剪掉会伤答案的节点；
但这些 sparse feature 节点还没能稳定组成 evidence-linked route。
```

所以最合理解释是：

```text
当前 Qwen-PLT 没有把关键因果子空间拆成少数可解释 feature。
```

## 最推荐的一句话摘要

```text
Gemma 证明了这条路线可以被完整追踪；Qwen 证明了同类因果流也存在，但它的路线不一定以 Gemma 那种稀疏节点图的形式出现。
```
